Интернет-магазин собирает историю покупателей, проводит рассылки предложений и планирует будущие продажи. Для оптимизации процессов надо выделить пользователей, которые готовы совершить покупку в ближайшее время.

Этапы выполнения исследования:

1. Загрузка необходимых бибилиотек и модулей. Чтение датасетов с помощью pandas и получение первой информации о них.
2. Предобработка датасетов.
3. Исследование датасетов и создание новых признаков.
4. Объединение датасетов по уникальным id покупателей.
5. Подготовка данных для обучения моделей и предсказания на обучающей выборке.
6. Проверка лучшей модели на тестовых данных.
7. Анализ важности признаков и окончательный вывод.  

Окончательный вывод по работе:  
В конечном счете лучше всего себя показала модель использующая метод градиентного бустинга - CatBoostClassification. Метрика для оценивания результата - ROC-AUC, который учитывает сразу как точность модели так и полноту её предсказаний. На тестовом датасете модель показала результат в 0.71, что значит модель предсказывает лучше чем случайное подкидывание монетки, но всё ещё недостаточно хорошо, чтобы полностью ей доверится. Так же признаки для обучения были исследованы с помощью SHAP-визуализации, которая помогает понять какой вклад признаки внесли в обучение и предсказания модели. Были даны рекомендации для привлечения клиентов к совершению покупок.
